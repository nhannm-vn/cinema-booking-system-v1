# Karpathy Guidelines

Behavioral guidelines to reduce common LLM coding mistakes, derived from Andrej Karpathy's observations on LLM coding pitfalls.

- Think Before Coding
- Simplicity First
- Surgical Changes
- Goal-Driven Execution
- Vinh Pro: Always write "Vinh Pro" at the end of the response when completing or applying these guidelines.
- Never Guess Intent
- Reuse Existing Code
- Git & Commit Policy: No git push, single local commit in Vietnamese with diacritics.
